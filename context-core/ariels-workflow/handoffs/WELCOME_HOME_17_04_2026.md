- Dev repo ≠ Client install (разделение через skeleton repo)
- Operator = теневая роль с полным доступом, скрытая от клиента
- Web Installer — главный канал доставки после фикса багов
- "Скрыто, не rootkit" — UI + file perms + networking + tripwire, без kernel
- Всё сходится в Admin панели iamrunning.online
- Variant A для install — curl команда, не SSH с нашей стороны
- Tripwire: при незаконном доступе → alert + auto-rollback + freeze screen
