# SOURCE OF TRUTH — Индекс

Эта папка содержит документы которые являются **законом** при разработке.
Любая нейросеть ОБЯЗАНА прочитать релевантные файлы из этой папки ПЕРЕД началом работы.

## Файлы

| Файл | Когда читать |
|------|-------------|
| `WORKER_MECHANICS.md` | **ВСЕГДА** — при любой работе с ролями, workflow, Dashboard UI, MCP tools. Это основной документ системы. Содержит: что такое система, 3 петли (Таски/PR/Сообщения), закон паритета Dashboard=AdminPanel, чеклист новой роли с точными именами файлов, таблицу навигации по ключевым файлам. |

## Правило

Если handoff документ не упоминает source-of-truth — это баг в handoff.
Каждый handoff для работы с ролями/workflow ОБЯЗАН содержать:

```
ОБЯЗАТЕЛЬНО: Прочитай source-of-truth/WORKER_MECHANICS.md перед началом работы.
Каждый пункт из этого файла — закон. Если не реализовано — workflow не закрыт.
После реализации — пройди WORKFLOW ВЕРИФИКАЦИЮ из этого файла пункт за пунктом.
```
