# Workspace

Team workspace — создавай файлы здесь через Work System.

Все изменения от developer/reviewer идут через PR → проверка admin → деплой.

## Как создать файл

1. Work System → 📄+ (New File)
2. Введи название: `my-file.md` (или `docs/my-spec.md`)
3. Напиши содержимое в редакторе
4. Нажми **Submit PR**
5. Admin проверяет и апрувит

## Структура

```
workspace/
├── docs/       — Документация, спецификации
├── plans/      — Планы и задачи
└── *.md        — Общие файлы команды
```
