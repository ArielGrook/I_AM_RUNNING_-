# Self-Learning AI Workspace — Core Concept
*Captured: 07.04.2026*

## Идея в одной фразе

**Клиент замкнутого цикла со встроенным AI который дообучается на твоих собственных файлах прямо внутри интерфейса.**

## Почему это разрывает рынок

Cursor, Windsurf, Claude Code — статичные инструменты. Они не знают твой проект. Ты каждый раз объясняешь контекст заново.

iamrunner.ai — живой инструмент. Чем больше работаешь, тем умнее становится именно для тебя.

## Замкнутый цикл

```
Работаешь в приложении
      ↓
Drag & drop файлы / логи / документация
      ↓
Приложение само структурирует → датасет
      ↓
Fine-tune QLoRA прямо внутри (кнопка)
      ↓
Модель знает твой проект лучше всех
      ↓
Работаешь быстрее → больше данных → цикл
```

## Три режима обработки

1. **RAG** — мгновенно. Чанки → embeddings → Vectra. Сразу доступно для запросов.
2. **Dataset** — AI читает файл → генерит Q&A пары → dataset.jsonl
3. **Both** — RAG сразу + датасет фоном

## Fine-tune кнопка

Появляется когда dataset.jsonl > порогового количества примеров.
Запускает Unsloth + QLoRA локально (RTX 3050, 7B модель впритык).
Итог: новый LoRA адаптер ~200MB поверх базовой Qwen2.5-Coder 7B.

## Бизнес-импликация

- Адаптер зашифрован + привязан к подписке клиента
- Каждый клиент получает модель обученную на ЕГО кодовой базе
- Чем дольше клиент — тем ценнее его адаптер → не уйдёт
- Ежемесячный re-train = причина платить подписку
