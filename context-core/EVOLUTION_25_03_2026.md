144. DEV-AGENT CONTEXT-CORE LOADING — ДИНАМИЗАЦИЯ (архитектурное решение 25.03.2026)
Текущий loadContextCore() в app/api/dev-agent/route.ts грузит из фиксированного
CONTEXT_CORE_DIR = join(PROJECT_ROOT, 'context-core'). Для Option A нужно сделать
его динамическим: принимать clientSlug из x-client-slug заголовка запроса,
подставлять путь /var/www/iam-clients/SLUG/context-core/. Если slug нет —
fallback на стандартный context-core (поведение для основного проекта).
Это 5-7 строк изменений, не требует нового endpoint.

145. INSTALL-CLIENT.SH УПРОЩЕНИЕ ДЛЯ OPTION A (25.03.2026)
Текущий install-client.sh создаёт отдельный PM2 процесс на клиента (Option B логика).
При Option A скрипт упрощается: только создание /var/www/iam-clients/SLUG/context-core/
из шаблона, запись .env клиента, добавление Nginx server block с X-Client-Slug.
PM2 не трогается. Скрипт становится быстрее и надёжнее.
