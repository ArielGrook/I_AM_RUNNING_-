142. МУЛЬТИТЕНАНТНОСТЬ — ФИНАЛЬНОЕ РЕШЕНИЕ: OPTION A 25.03.2026
После попытки Option B (отдельный PM2 на клиента) обнаружен критический баг:
несколько PM2 процессов из одного cwd конфликтуют за один .next билд →
"Could not find a production build" error. Option A принят окончательно:
один PM2 (порт 3000), Nginx добавляет X-Client-Slug заголовок, middleware.ts
читает заголовок и роутит на клиентские страницы. Все клиенты шарят один билд.
Данные клиентов изолированы в /var/www/iam-clients/SLUG/. MCP грузит context-core
из нужной папки по токену. install-client.sh переписывается под новую логику:
вместо PM2 — только Nginx config + файлы клиента.

143. КЛИЕНТСКАЯ АРХИТЕКТУРА — ЧТО ПОЛУЧАЕТ КЛИЕНТ 25.03.2026
Ключевое решение: клиент НЕ получает embedded chat интерфейс в браузере.
Клиент работает в Claude.ai или ChatGPT — привычном AI интерфейсе. Система
живёт на сервере и подключается через MCP коннектор. Это и есть суть продукта:
AI уже знает контекст клиента до начала разговора. Grisha открывает Claude,
вставляет bootstrap промт — и Claude говорит "продолжаю с того места где
остановились". Без авторизации, без сложного UI, без embedded chat.
Embedded chat — feature for v2.

144. CHATGPT КАК ИНСТРУМЕНТ РАЗРАБОТКИ — ВЫВОДЫ 22-25.03.2026
Практический опыт использования ChatGPT для разработки лендинга:
несколько итераций с подробными промтами дали нестабильный результат —
каждая попытка частично ломала предыдущее. GPT галлюцинирует в длинных сессиях,
теряет контекст, смешивает инструкции. Вывод: ChatGPT не подходит для
итеративной разработки с накопленным состоянием. Работает только для:
- написания изолированных компонентов по точной спецификации
- генерации markdown документов по шаблону
- ответов на архитектурные вопросы (без выполнения)
Claude (Opus/Sonnet через MCP) — единственный надёжный инструмент для
разработки проекта. Правило: любая задача требующая чтения реального кода
и итеративных правок → только Claude через MCP.

145. ЛЕНДИНГ — СТАТУС И ПРИОРИТЕТ 25.03.2026
Лендинг прошёл несколько итераций (v1 оранжевый hero → v2 с HostingSection +
SavingsCalculator → v3 попытка ChatGPT → откат). Текущий коммит: landing v3.
Проблемы: hero недостаточно оранжевый по вкусу, dark mode серый вместо чёрного,
нет нормального светлого режима, ряд секций требует переработки.
Решение: лендинг ДЕПRIORITIZED до тех пор пока не будет живого клиентского кейса.
После первой продажи — полный редизайн лендинга с чётким ТЗ и без итераций.
Бизнес-кейс важнее визитной карточки.
