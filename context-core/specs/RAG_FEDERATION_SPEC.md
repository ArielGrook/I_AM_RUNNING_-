## Философия
Организация учится как организм. Знания распространяются через RAG-протокол. Каждый reject — тренировочный сигнал. Каждый approve — подтверждение паттерна. Одна модель, обученная на всех.

**ПРАВИЛО: ВСЕ RAG чанки, датасеты — ТОЛЬКО НА АНГЛИЙСКОМ.**

## 5 слоёв
1. **Персональный RAG** — на машине воркера (файлы, время, tool calls)
2. **Групповой RAG** — агрегация по ролям (developers, reviewers, admins)
3. **Компиляция** — Master node, кросс-ролевые связи, датасет
4. **Fine-tune** — LoRA на одной модели (не отдельные по ролям)
5. **Дистрибуция** — обновлённая модель всем воркерам
