## 6. FASTEST POSSIBLE MVP

The first MVP should not try to solve everything.
It should prove that the system can be used by a real operator/business.

### Minimum viable core

#### 1. Web access
- usable from browser
- usable from different devices
- no dependence on one local machine

#### 2. AI chat integration
- user can work through ChatGPT or Claude
- AI can read project memory and operate in context

#### 3. Context core
- system identity
- architecture
- project structure
- engineering memory
- debug map
- rules
- progress

#### 4. Safe working surface
- dev console or equivalent operational UI
- file visibility
- controlled edits
- deploy / rollback / runtime actions where relevant

#### 5. Task execution pattern
- user describes desired result
- AI breaks it down
- AI works against a documented environment
- system state is updated in docs after work

#### 6. One real business use case
The MVP should target one specific workflow, not every business workflow at once.
