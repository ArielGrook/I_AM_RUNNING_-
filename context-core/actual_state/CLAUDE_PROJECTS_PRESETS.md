# Claude.ai Projects — Presets для каждой роли

Инструкция по настройке Claude.ai Projects для командной работы в IAM Client OS.

**Что это дает:** Claude в Projects автоматически знает свою роль, инструменты и правила с первого сообщения.

---

## Как настроить

1. Claude.ai → Projects → Создать проект
2. Project Settings → вставить Instructions для роли
3. Knowledge → загрузить Memory файлы
4. MCP Connector: URL + Bearer токен

---

## 4 роли: Super Admin, Admin, Developer, Reviewer

Полные Instructions и Memory файлы для каждой роли — в этом документе.
Детали: см. source-of-truth/WORKER_MECHANICS.md на сервере IAM Client OS.
