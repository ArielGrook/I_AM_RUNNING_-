## 1. Что такое продукт — питч для дяди

### Одна фраза
> **I AM RUNNING Team Workspace** — это операционная система для команды, где ИИ (Claude) является основным рабочим инструментом, а не ассистентом.

### Проблема которую мы решаем
Обычная команда работает так: задачи в Jira, код в GitHub, общение в Slack, ИИ где-то сбоку в ChatGPT. Всё разрозненно, контекст теряется, ИИ не знает о проекте ничего.

Мы решаем это так: **всё в одной системе, ИИ подключён к проекту через MCP** — он видит файлы, задачи, историю, может вносить изменения через PR систему.

### Роли
| Роль | Что может |
|------|-----------|
| Super Admin | Всё + SSH, невидим в системе |
| Admin (Aliks) | Управляет командой, review PRs, deploy |
| Developer (Steve) | Работает через ИИ, создаёт PRs |
| Reviewer (Troy) | Проверяет код, approve/reject PRs |

## 2. Онбординг с нуля — пошагово

### Шаг 1: Новый пользователь получает токен
Admin Panel → Team → Add Member → имя + роль → копировать токен (показывается один раз)

### Шаг 2: Вход в дашборд
Открывает URL → вставляет токен → Enter → видит дашборд

### Шаг 3: MCP коннектор к Claude
Dashboard → Setup tab → копировать MCP URL + Bootstrap Prompt
Claude.ai → Settings → Integrations → Add MCP Server

### Шаг 4: Первое действие
Admin создаёт задачу → push → worker в Claude → read_memory → работает
