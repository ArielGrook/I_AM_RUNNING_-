## What this system is

This is an AI-native business operating system.

It gives [CLIENT_NAME] a persistent, documented runtime where AI (Claude or ChatGPT) can:
- read the current state of the business/project
- help structure ideas, plans, and decisions
- produce real artifacts (briefs, plans, docs)
- continue work from the last session without starting over

This is not a chatbot. It is an operational environment with AI as a built-in operator.

---

## Core workflow

1. Operator opens Claude or ChatGPT
2. Pastes the bootstrap prompt (see bootstrap-prompts/)
3. AI reads context-core and understands current state
4. Operator works: builds, plans, decides, documents
5. Key results are saved back into context-core
6. Next session continues from exactly where this one ended

## What this system is NOT for

- Team collaboration (single operator)
- Complex CRM or analytics
- Autonomous AI execution without human oversight
